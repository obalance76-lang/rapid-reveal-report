Evaltech- a documentation app of  Security process for Ethical Hacking

Generate a text logo for Evaltech. The main colours Orange, black and white

How it works: it does a quick analysis of a site link you submit for  vulnerabilities. This is an initial fast check to see how vulnerable the site is, with a score and a report

The main thing: The app has a button for a downloadable pdf that is professional and well-formatted. The document has the vulnerabilities, and tools that are used and tools that can be used. 

Has a quick Analyze and long analyze for vulnerabilities

The idea is you load a link and and show the report of its vulnerabilities

The best feature is the one that allows to download a professionally well formatted pdf:

First you can download an introductory pdf of the site after you just loaded, that displays how secure it is and the vulnerabilities through its quick initial check.

Then there is a section where 5 downloadable pdfs appear. These are quick assessments each of vulnerable the site is to 5 cyber attack threats each.
